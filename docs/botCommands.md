# Bot Commands

On an open game or app preset issue, a listed approver or repository administrator can comment:

- `@LizardByte-bot approve` to put the request in the approval queue.
- `@LizardByte-bot check` to rerun validation.

The issue author may also use `@LizardByte-bot check`. The bot reacts to commands it accepts. Editing an issue body runs validation automatically.
